## Reverse 配置菜单

启动器会递归扫描 `config/` 下的 YAML；已反馈会压线的 `HS70_070_y002_curve022.yaml`、`L_vision_050.yaml`、`M_vision_055.yaml` 从交互菜单隐藏，但文件仍保留，仍可用 `--params` 手动指定。Reverse 配置显示 `[Reverse 制动实验]` 标记。每项后面的使用次数记录在 `~/rdkx5_logs/parameter_usage.tsv`。菜单编号会变化，建议直接按文件名启动，例如：

```bash
bash src/scripts/start_line_following.sh \
  --params RB_C11_058_reverse040.yaml
```

Mac 上运行 `src/scripts/watch_parameter_presets.sh start` 可启动 30 秒轮询同步；新增或更新 YAML 后会自动复制到车端。查看状态用 `status`，停止用 `stop`。同步进程在当前登录会话运行，Mac 重启或注销后需重新执行 `start`。

反向制动代码和这些配置尚未完成板端构建与实车验收。测试前需同步对应 YAML 和源码、重新构建 `line_follower`；不要只同步参数文件。

## 2026-11-01 岔路图提速

用户实车反馈 `RB_S070_070_R040_P050_Y005_CURVE_PREVIEW_F050_RC026/028/030.yaml` 三组在岔路图**效果非常好**。三组目标 0.70 m/s、上限 0.75 m/s，仅 `reverse_curve_speed` 为 0.26 / 0.28 / 0.30；菜单启动计数 1 / 0 / 2 次，计数不代表圈数。

据此生成：

- 0.73 单变量对照三组：`RB_S073_075_..._RC026/028/030.yaml`，只把 `target_speed` 从 0.70 提到 0.73，`max_speed` 仍为 0.75，其余参数不变。
- 0.78 防压弯组：`RB_S078_083_..._RC026_NOCUT.yaml`，在 RC026 基础上把 `max_yaw_rate` 提到 1.65、`kp` 提到 2.50、`speed_gain_damping` 提到 0.70、`sharp_curve_threshold` 降到 0.48；保留 0.20 m/s 急弯限速和 0.26 m/s 反向弯限速。

0.73 三组和 0.80 组尚未实车验证；0.78 NOCUT 已实车反馈非常不错，因此只再加一组 0.80 作为下一档：`RB_S080_085_R040_P050_Y005_CURVE_PREVIEW_F050_RC026_NOCUT.yaml`，只把 `target_speed` 0.78→0.80、`max_speed` 0.83→0.85，其余防压弯参数全部不变。建议 0.73 三组做单变量对照，0.80 作为 0.78 的下一档。若出现压线，先降 `target_speed`；内侧压线可降 `curve_preview_max_far_weight`，外侧压线可升 `curve_preview_max_far_weight` 或 `max_yaw_rate`。不要同时改多个参数。
