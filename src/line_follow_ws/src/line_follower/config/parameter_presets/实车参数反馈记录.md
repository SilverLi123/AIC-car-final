## Reverse 配置菜单

启动器会递归扫描 `config/` 下的 YAML；已反馈会压线的 `HS70_070_y002_curve022.yaml`、`L_vision_050.yaml`、`M_vision_055.yaml` 从交互菜单隐藏，但文件仍保留，仍可用 `--params` 手动指定。Reverse 配置显示 `[Reverse 制动实验]` 标记。每项后面的使用次数记录在 `~/rdkx5_logs/parameter_usage.tsv`。菜单编号会变化，建议直接按文件名启动，例如：

```bash
bash src/scripts/start_line_following.sh \
  --params RB_C11_058_reverse040.yaml
```

Mac 上运行 `src/scripts/watch_parameter_presets.sh start` 可启动 30 秒轮询同步；新增或更新 YAML 后会自动复制到车端。查看状态用 `status`，停止用 `stop`。同步进程在当前登录会话运行，Mac 重启或注销后需重新执行 `start`。

反向制动代码和这些配置尚未完成板端构建与实车验收。测试前需同步对应 YAML 和源码、重新构建 `line_follower`；不要只同步参数文件。
