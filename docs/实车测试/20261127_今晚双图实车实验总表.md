## §5 录包分析与现场快速调参决策表

### 5.1 单包分析与整晚多包横向汇总

```bash
# 查看单个录包详细报告（耗时 < 2s）
python3 src/scripts/analyze_bag.py recorded_bags/<bag_dir>

# 汇总整晚所有录包生成 Markdown 横向对比表，并导出文件
python3 src/scripts/analyze_bag.py --compare recorded_bags/ \
  --markdown docs/实车测试/20261127_今晚录包汇总.md
```

重点关注的量化指标：
- **`MaxLatA` & `Flips`（`avoid` 栏目）**：直接衡量红障避让平顺度。`R3` 目标相对昨天的 `OPT3_S060` 明显降低 `MaxLatA` 与 `yaw_sign_flips`（理想为 `0` 或 `1`）。
- **`MaxCoast(cm)`（`braking` 栏目）**：反向制动生效时黄线前冲应稳定在 `8–12 cm`；若明显增大需查 `/odom` 延迟或提高 `reverse_speed` 幅值。
- **`T-Merge`（`triggered / rescued / exited`）**：Fork 图重点看每次过红框是否稳稳 `1/0/1`（或有 `rescued` 救回且 `LOST` 帧极少）。
- **`FPS / MaxGap(ms)`**：确保 `/image_raw` 稳定在 `~30 FPS` 且无大幅卡顿。
