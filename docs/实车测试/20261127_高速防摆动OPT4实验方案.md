### 2. 高速避让大摆动的三个机理根因
1. **横向加速度随速度平方感放大（$a_y = v \cdot \omega$）**：
   - 原本固定上限 `red_avoid_max_yaw_rate` 为 `1.35–1.45 rad/s`：低速（`0.22 m/s`）时对应侧向加速度 $a_y = 0.22 \times 1.25 = 0.275\text{ m/s}^2$；但高速入障瞬间车速还在 `0.55–0.65 m/s`，若 $\omega$ 给到 `1.35`，瞬时侧向加速度高达 $0.88\text{ m/s}^2$（超低速 3 倍以上），直接猛甩横移。
2. **减速滞后与斜率偏大**：
   - 从 `0.60+ m/s` 收到减速指令后，物理轮速（`/odom`）回落到 `0.26 m/s` 存在约 `0.2–0.3 s` 惯性滞后；在速度还没降下来时按 `red_avoid_yaw_slew_rate: 5.0–5.6` 猛推舵角，车头会一次性偏转过头。
3. **出障后反甩与 `kp` 回拉共振**：
   - 出障保持窗 `0.35 s` 偏短，刚躲过锥桶车身还带着较大偏差角与残余角速度时突然切回高压 `kp`（`2.95–3.05`）巡线，引发“先往外甩、再猛往回抽”的双次大摆。

## 二、OPT4 核心改进：`red_lat_accel_limiter.hpp`

新增头文件 [`src/line_follow_ws/src/line_follower/include/line_follower/red_lat_accel_limiter.hpp`](../../src/line_follow_ws/src/line_follower/include/line_follower/red_lat_accel_limiter.hpp)，引入 2 个默认关闭（完全向后兼容）的动态约束参数：

1. **`red_avoid_max_lat_accel`（默认 `0.0` 关闭；OPT4 开启为 `0.28–0.34 m/s²`）**：
   - 取有效速度 $v_{\text{eff}} = \max(v_{\text{cmd}}, v_{\text{odom}})$（若 `/odom` 超过 `0.25 s` 未更新则退回 $v_{\text{cmd}}$），保证减速滞后期间仍受高速限幅保护。
   - 动态角速度上限：$\omega_{\max}(v_{\text{eff}}) = \min\big(\text{red\_avoid\_max\_yaw\_rate},\; \frac{a_{y,\max}}{\max(v_{\text{eff}}, 0.18)}\big)$。
   - **效果对比**（以 `lat_accel = 0.34`、`red_avoid_max_yaw_rate = 1.12` 为例）：
     - 高速刚看到红锥瞬间（$v_{\text{eff}} = 0.60$）：角速度自动压到 **`0.57 rad/s`**（平稳滑出躲避轨迹，绝不猛甩）；
     - 减速中段（$v_{\text{eff}} = 0.40$）：自动放开到 **`0.85 rad/s`**；
     - 低速贴弯死角（$v_{\text{eff}} = 0.22$）：保留 **`1.12 rad/s`** 满额绕行权限，不会因为限幅而撞弯道锥桶。
2. **`red_avoid_highspeed_slew_ref_speed`（默认 `0.0` 关闭；OPT4 开启为 `0.28–0.30 m/s`）**：
   - 当 $v_{\text{eff}} > v_{\text{ref}}$ 时按 $v_{\text{ref}} / v_{\text{eff}}$ 缩放避障转向变化率（最低保留 `0.45x`），高速切入更柔和、低速退出不拖沓；同时配合上延前视 `red_roi_top_ratio: 0.41–0.43` 和更长的退出保持窗 `red_avoid_release_hold_sec: 0.48–0.55`。

### 判据与调参口诀
- **若 `E2` 出弯/出障还有摆动、不够柔顺** → 直接测 `E3`（`lat_accel=0.28`、`slew=3.0`）。

- **若 `E2` 过红障非常稳且想压圈速** → 优先测 `E5`（只提干净弯道速度，风险最低）再测 `E4`（直道提速）。
