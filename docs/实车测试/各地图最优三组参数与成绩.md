# 各地图最优三组参数与成绩

本表按**地图**分别维护，不把不同地图的成绩放在一起比较。参数以 YAML 文件名为准，不用启动菜单编号。

## 排名口径

- 只有完整跑完且无压线的记录，才能进入该地图的有效前三。
- 记录圈速、实测次数、完赛次数和停车情况；有多次有效成绩时，同时记录最好成绩和中位数。
- 未提供圈速或结果不完整的先列为候选，不虚构名次或成绩。
- 参数文件发生变化时，复制出新文件名再测试，保留原记录可追溯。
- 圈速包含黄线停车时间，不同 `yellow_stop_duration` 的圈速不能直接当作控制性能比较。

### 切换顺序

1. 默认 A（0.45 s）。已跑 1 圈 20.779 s，赛前建议再补 2 圈确认；预期与 B 接近。
2. 如果现场黄线计数不稳（未到 4/4 就恢复、或黄线未清除就起步），换 B（0.50 s）。B 有 5 圈实测，停车余量更大。
3. 如果黄线计数稳定但觉得停车偏长，换 C（0.40 s）。C 是当前最快单圈。
4. 如果问题是丢线、压线或转向摆振，换这三组没有用：三组的转向和速度完全相同。应降速或调 `kp`，可先用环岛历史候选 `C11_058_curve025_y0020_hold10.yaml` 或 `HS65_065_y002_curve022.yaml` 做保守组。
