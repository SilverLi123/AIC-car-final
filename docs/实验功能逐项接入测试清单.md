## 一、第一步：建立独立实验目录并一次性编译（不覆盖基线）

连上小车热点后，先在车端复制一份独立实验目录，再在 Mac 仓库根目录同步并编译：

```bash
# 1. 在车端克隆独立实验目录（首次执行；保留 ~/aic_car_final 基线完好）
ssh sunrise@172.20.10.2 '
  if [ ! -d ~/aic_car_final_exp ]; then
    cp -a ~/aic_car_final ~/aic_car_final_exp
  fi
'

# 2. 同步修改后的源码、头文件、launch、参数文件、启动脚本和 YOLOv8 推理脚本到 ~/aic_car_final_exp
scp \
  src/line_follow_ws/src/line_follower/include/line_follower/line_follower_node.hpp \
  src/line_follow_ws/src/line_follower/include/line_follower/digit_decision_logic.hpp \
  sunrise@172.20.10.2:~/aic_car_final_exp/src/line_follow_ws/src/line_follower/include/line_follower/

scp \
  src/line_follow_ws/src/line_follower/src/line_follower_node.cpp \
  src/line_follow_ws/src/line_follower/src/detection_turn_controller.cpp \
  sunrise@172.20.10.2:~/aic_car_final_exp/src/line_follow_ws/src/line_follower/src/

scp \
  src/line_follow_ws/src/line_follower/launch/line_follower_with_detection.launch.py \

scp \
  src/line_follow_ws/src/line_follower/config/line_follower_params.yaml \
  sunrise@172.20.10.2:~/aic_car_final_exp/src/line_follow_ws/src/line_follower/config/

scp \
  src/line_follow_ws/src/line_follower/config/parameter_presets/EXP_*.yaml \
  sunrise@172.20.10.2:~/aic_car_final_exp/src/line_follow_ws/src/line_follower/config/parameter_presets/

  src/scripts/start_line_following.sh \
  sunrise@172.20.10.2:~/aic_car_final_exp/src/scripts/start_line_following.sh
```

## 二、建议测试顺序（先基线、再单项、后组合）

1. **先用 `~/aic_car_final_exp` 默认全关配置跑 0.30 m/s、不带 YOLO**：
   ```bash
   cd ~/aic_car_final_exp
   bash src/scripts/start_line_following.sh --params line_follower_params.yaml
   ```
   单测 `191ba0f` 的**红锥同向不叠加**效果：对照昨晚视频里的两个右弯外侧红锥，确认右侧车轮全程留在白路内、且不撞锥。
2. **随后单测 `EXP_01`（红禁行区聚类 + 接近后锁存单边绕行）**：
   确认地上 24×13cm 红框/红胶带能整块识别且平滑单边绕过，不摇晃。
3. **离线对比新旧 YOLO `.bin` 后再接数字模块**：
   通过 `--yolo-model src/yolov8/mod1/best_modified_yolov8_v2.bin --yolo-roi-filter` 一键切换 v2 模型与几何过滤，依次单独验证 `EXP_02`（数字投票与闭环收尾）、`EXP_03`（红障屏蔽数字框；默认 `digit_mask_apply_to_yellow=false` 不抹黄线）、`EXP_04`（黄线几何+停稳确认）。
4. **单项全部确认无退化后，再跑 `EXP_05` ~ `EXP_08`**（尤其是同时开高速与反向制动的 `EXP_08`）。

## 四、单项微调说明

| 顺序 | 对应模块 & 开关 | 实车验收标准 | 异常怎么调 / 回退 |
|---:|---|---|---|
| **0** | **基线复测**（`191ba0f`） | 弯道外侧红锥绕行时右后轮不切内圈黑线，也不撞锥 | 仍轻度切内弯 → 降 `red_soft_yaw`（`0.15 → 0.12`）；撞锥 → 升 `red_repulsion_gain` |
| **1** | **`EXP_01` 红禁行区** | 过地上红框/红胶带平滑单边绕过，不摇晃 | 仍碎裂漏判 → 调大 `red_zone_close_kernel_w/h`（`21 → 25`）或降 `red_zone_min_width_ratio`（`0.16 → 0.12`） |
| **2** | **v2 模型 + ROI 过滤** | 场外高处无误检；关闭 `rqt` 时 `"auto"` 自动停发调试图 | 远距刚露头数字被裁 → 调小 `roi_y_min_ratio`（`0.18 → 0.12`）；近处大框被滤 → 调大 `max_box_size_ratio`（`0.35 → 0.45`） |
| **3** | **`EXP_02` 数字决策** | 高速不漏触发；单帧多框/误检 8 不乱拐；双数字选大；转完不甩尾 | `launch` 已去掉 `high_timeout: 0.5` 覆写，现生效 YAML `0.12`；分叉不够拐 → 升 `turn_duration`（`0.38 → 0.45`）；直道微调太猛 → 降 `straight_max_yaw_rate` |
| **4** | **`EXP_03` 数字框屏蔽** | 红底干扰数字不被当红锥躲开；分叉真黄线不被抹掉 | 红框边缘残留仍触发 → 调大 `digit_mask_pad_px`（`8 → 14`）；若确实需屏蔽黄底数字才手动设 `digit_mask_apply_to_yellow: true` |
| **5** | **`EXP_04` 黄线 & 停稳** | 黄色干扰不误停；每次真实黄线车速归零且角速度稳定后起步 | 真黄线倾斜漏判 → 调小 `yellow_min_aspect_ratio`（`2.5 → 1.8`）；停等过久 → 确认 `/odom` 频率并微调 `yellow_still_hold_sec`（`0.15 → 0.08`） |
