## 二、逐项开启与实车验收顺序

每次**只多打开 1 个开关**，跑 1~2 圈确认无退化后再开下一个。所有开关默认位置均在 `src/line_follow_ws/src/line_follower/config/line_follower_params.yaml`（第 2 项在 `bpu_yolov8_node.py` 启动参数）。

| 顺序 | 对应模块 & 开关 | 怎么开 | 实车验收标准 | 异常怎么调 / 回退 |
|---:|---|---|---|---|
| **0** | **基线复测**（`191ba0f` 红锥同向不叠加） | 全关，直接跑 `line_follower_params.yaml`（不带 `--yolo`） | 弯道外侧红锥绕行时**右后轮不再切内圈黑线**，也不撞锥 | 若仍有轻度切内弯，把 `red_soft_yaw` 从 `0.15` 微降到 `0.12`；若撞锥，调大 `red_repulsion_gain` |
| **1** | **红禁行区聚类合并 + 方向锁存** | `enable_red_zone_lock: true` | 过地上红胶带/红框时**一条平滑弧线绕过**，不再左右摇晃 | 仍会分叉漏成碎块 → 调大 `red_zone_close_kernel_w/h`（如 `19/11`）或减小 `red_zone_min_width_ratio`（如 `0.12`）；出问题设回 `false` |
| **2** | **新 YOLOv8 `.bin` + 几何/ROI过滤** | 启动 `bpu_yolov8_node.py` 时加：<br>`--ros-args -p model_path:=新模型.bin -p enable_roi_geo_filter:=true` | 场外高处无误检；关闭 `rqt` 时默认 `"auto"` 模式下帧率更高；新模型 1~8 识别稳定 | 远距离刚露头数字被裁掉 → 调小 `roi_y_min_ratio`（`0.18 → 0.12`）；近处大框被误滤 → 调大 `max_box_size_ratio`（`0.35 → 0.45`） |
| **3** | **数字决策升级 + `mux` 超时修复** | `enable_robust_digit_decision: true` | **高速不漏触发**；单帧误检 8 不乱拐；分叉口双数字稳定选大；转完**及时回巡线不甩尾踩线** | 注意：`launch` 已去掉 `high_timeout: 0.5` 覆写，现在生效的是 YAML 里的 `0.12`！若分叉转向变短不够拐 → 适当调大 `turn_duration`（`0.38 → 0.45`）或调小 `close_loop_x_tol`；直道微调太猛 → 降 `straight_max_yaw_rate` |
| **4** | **巡线红/黄滤镜屏蔽 YOLO 数字框** | `enable_yolo_digit_masking: true` | 贴**红底/黄底干扰数字**测试时，小车不会把数字当成红锥躲开或当黄线停车，稳稳压过拿 Bonus | 边缘残留红色像素仍触发 → 调大 `digit_mask_pad_px`（`8 → 14`）或降低 `digit_mask_min_conf`（`0.40 → 0.30`） |
| **5** | **黄线几何过滤 + `/odom` 停稳确认** | `enable_yellow_geo_filter: true`<br>`enable_yellow_odom_stop_confirm: true` | 黄色干扰标贴不误停；每次真实黄线前**车速真正归零并保持静止后才起步**，不吃 +15s 罚时 | 真黄线倾斜导致漏触发 → 调小 `yellow_min_aspect_ratio`（`2.5 → 1.8`）或 `yellow_min_width_ratio`（`0.25 → 0.18`）；起步偏慢 → 缩短 `yellow_still_hold_sec`（`0.15 → 0.08`） |

## 三、全开启后的提速路线

1. **0.30 m/s 全开关跑通 2 圈**（0 撞锥、0 压红框、0 踩线、黄线停稳、Bonus 触发稳定）。
2. 将实测稳定的开关段落复制到更高速度预设（例如 `P01_055` → `RB_C11_058` → `RB_S065` → `RB_S070_CURVE_PREVIEW`），每次只升一档速度跑 2 圈。
3. 如遇到某个模块在高速下表现边界，记得顺手用 U 盘录包（`/media/E56F-10AE5/aic_bags/`），回来看单帧日志即可精调对应参数。
